# Studio YUE2 翻唱

应用：国内站 `2101611194623807489`，国际站 `2101611337957187585`。以用户更新后的 `Timbre2Music(音色迁移)-YUE2.json` 为准，工作流副本 `yue2-cover-workflow.json` 保留反推和直接输入两种形态。

网站发送五个参数：#15 `text` 音乐风格、#16 `text` 编辑后的歌词、#31 `text` 当前歌曲已保存的 ABC、#32 `value` 固定布尔值 `false`、#14 `value` 固定 600.0。#37 Text Input Switch 的 text_a 来自反推支路，text_b 来自 #31；false 选择 text_b，再送入 #17 abc。600 秒是生成上限，不保证输出固定十分钟。#7 输出 MP3。只修改文本和布尔参数，保留节点连接；官方节点参数说明：https://www.runninghub.cn/runninghub-api-doc-cn/doc-8287336。

服务端按当前账号验证解析任务、原曲素材及回收站状态，只从已完成、来源一致的 `cover-inference` 记录读取 ABC；客户端提交的 ABC、时长、渠道和工作区覆盖值均不使用。翻唱提交不会上传音频，也不会提交新的解析任务。使用现有双站自动分配与幂等提交，未知提交状态不会自动重跑。

应用参数示例仅列公开表单字段，不用其列表判断节点能否通过 nodeInfoList 覆盖。使用和之前 YUE2 boolean 相同的参数覆盖方式，#32 传 JSON 布尔值 false。网站不再次提交独立的解析任务；普通文本开关不保证跳过工作流内部另一支路的执行。

风格留空时优先使用原作品已保存的风格；上传歌曲无风格资料时由 DeepSeek 构思。风格框提供 AI 润色，沿用 YUE2 的 Genre、Vocals、Language、Tempo、Instruments 指导；只更新风格，不改变歌词或名称，等待期间的新输入不会被旧结果覆盖。名称留空时由 DeepSeek 根据当前歌词与风格起独立曲名，不沿用文件名或添加翻唱后缀。风格和命名返回格式异常或超长时，在原45秒超时预算内最多再请求一次文本修正，仍不合格则在提交 RunningHub 前报告错误，不重复提交音乐任务。歌词语言在发给生成 API 的风格中补充，不改用户风格输入。结果保存到当前用户的 R2 音频库和 D1 生成记录，在 Songs 工作区自动导入，并支持 Studio 的播放、MP3 下载、刷新恢复和继续编辑。

翻唱进入队列后，Studio 以生成任务 ID 调用现有单曲封面接口，复用 DeepSeek 视觉提示词规划、双站图片生成、主题备用图及同步保存。封面采用新曲名、实际歌词和 styles 或后台 coverStyles，与 Songs 工作区共用同一条封面记录。重复提交或刷新沿用已存在的封面（包括上传的封面），原曲解析和语音变声不自动生成图片。Studio 列表及右侧预览显示封面，更新图片时不重建音频播放器。
