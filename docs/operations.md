# 后台管理

用管理员账号登录后，在「我的账号 → 后台管理」或直接访问 `/admin/`。
普通账号没有后台权限。页面与所有管理 API 都在服务端验证管理员会话，不能用自定义身份头绕过。

## 日常查看

- **运行概览**：期间音频与封面任务、需要关注的任务、AI 接口调用、当前存储使用、数据库/NAS/后台同步/备份状态，以及最近任务动态。
- **任务记录**：查已有生成记录，按时间、用户与状态筛选。`failed` 是失败，`unknown` 是提交待核对，`fallback` 是封面使用备用图片，不能把它们都理解为歌曲生成失败。音频按创建时间筛选；封面旧表没有创建时间，按最近更新时间筛选。
- **操作与错误**：回看登录、密码设置、管理员调整、素材与工作区操作、AI 接口和任务状态变化、服务启动/停止、任务同步异常与恢复。正常轮询不逐条刷屏，相同错误在五分钟内合并并显示次数。
- **账号与存储**：沿用邀请制、账号启停、配额管理。邀请链接只给对应使用者，24 小时有效；不会写入运行日志。

默认查看最近七天，支持 24 小时、7/30/90 天。页面在前台时每 30 秒刷新，可关闭自动刷新。分页查看旧记录时不自动跳页；请求失败会保留上次结果并标明连接异常。时间统一显示北京时间。

「导出诊断记录」导出 JSON：当前时间和用户范围、概览、最多 1,000 条运行记录及 500 条任务，包含筛选条件。只向管理员提供。已登录管理员可以看到账号邮箱、任务名称及错误摘要，因此不要公开分发诊断文件。

## 记录从何时开始

已有音频/封面任务可以立即查看。详细操作、AI 请求耗时、HTTP 状态、网络错误码、DeepSeek 返回的 Token 用量从本次安装开始记录，不能补还以前没有采集的操作。概览调用数不含任务状态轮询，接口请求数不等于收费次数，不推算账单；供应商费用以供应商后台为准。查看与刷新后台不提交付费任务，也不修改 AI 调用限额。

运行记录放在正式 SSD 数据库 `sanzo_db` 的 `ops_events` 表，随原有数据库备份与恢复。保留最近 90 天，最多 50,000 条，写入时自动轮转。只选择必要的元数据，不保存请求/响应正文、歌词、提示词、密码、Cookie 或邀请链接；错误摘要会隐藏已配置的密钥和外部 URL。记录写入失败不会把原本成功的创作请求改成失败，并会输出固定错误码 `OPS_WRITE_FAILED`。

后台任务每 30 秒同步；现在会记录同步错误和恢复。应用启动修复中断的任务时也会记录状态变化。需要逐句歌词的同步位置仍为估算，与本工具无关。

## 备份状态接入

执行 `npm run storage:backup:install` 更新现有自动备份任务。当前 Mac 的原始状态仍位于 `~/Library/Application Support/SanzoMusic/backup-state`。

宿主机备份任务通过原有 Docker 权限，将 `schedule-status.json` 与 `last-backup.json` 的必要字段写入正式数据库的 `auth_settings.ops_backup_status`。即使当天已完成备份，每 15 分钟的计划检查仍会刷新这份摘要。手动备份完成后也会刷新摘要。网站读取数据库中的摘要，应用容器无需访问宿主机状态目录。

摘要仅含时间、状态、文件数、字节数、快照目录名和错误说明，不复制宿主机完整路径、配置或原始日志。备份失败、清理警告、超过 30 小时没有成功记录，或状态超过 35 分钟没有更新时提示关注。状态推送失败只记警告，不将已成功的备份误报成失败。网页没有 Docker socket 或 shell 权限。尚未接入时，如实显示暂无状态。

## 网站整体无法打开时

网站依赖应用本身运行。如果应用、Docker 或 Tunnel 整体离线，使用本机检查工具：

```sh
npm run ops:status
npm run ops:status -- --logs
```

也可双击项目里的 `operations-status.command`。它只读检查容器状态、NAS 标识、本机健康接口、Cloudflare Tunnel 就绪接口及自动备份，并可显示最近 30 行经过脱敏的容器输出，不需要网站账号或改密码。

当前工具用于主动查看，未接入邮件、短信或推送告警。
