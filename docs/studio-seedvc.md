# Studio 零样本变声

Speech 和 Songs 共用 SeedVC 应用：国际站 `2045880827887751169`，国内站沿用 `2108209006111182850`。源音频上传到节点 #18，参考音色上传到 #2；工作流分离人声、变声音色、合回源音频伴奏，读取 #30 的 MP3 输出。其余节点保留工作流默认值（30 步、速度 1、CFG 0.7、48 kHz、320k MP3）。

服务端根据所选工具设置 #14，浏览器不能自行覆盖：Speech 使用 `f0_condition=false`、`auto_f0_adjust=true`、`pitch_shift=0`；Songs 使用 `f0_condition=true`、`auto_f0_adjust=false`、`pitch_shift=0`，使歌曲沿用源人声的音高，不自动移调。这符合 [Seed-VC 官方说明](https://github.com/Plachtaa/seed-vc#usage)。

两种模式支持选择已有作品或上传 MP3 / WAV / FLAC，源音频和参考音色各不超过 32 MB。新上传的歌曲归为音乐素材，参考音色归为语音素材。结果分别保存为 Songs / Speech 作品，可在 Studio 底部播放器播放、预览、下载和编辑；删除、恢复与永久清空使用统一素材管理。

名称留空时使用“源文件名 · 参考音色名”，用户填写名称时保留原名。上传缓存按文件与素材类型区分；相同请求重试复用提交标识，未知提交状态不自动再次付费运行。仅处理属于当前用户且未进入回收站的音频，预设音色从网站静态资源读取。
