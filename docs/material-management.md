# 统一素材管理

左侧入口为素材管理，位于模型训练之后。主界面 `/create/#materials` 合并上传音乐、语音、ABC 文件以及已生成的创作作品和乐谱文本，提供来源筛选、类型筛选、搜索、排序、重命名、播放、乐谱预览和下载。生成音频按 assetId 与作品关联，同一文件不再作为上传素材重复列出；纯文本乐谱没有额外音频存储占用。

唯一回收站入口为 `/create/#materials-trash`。旧的 `#uploads` 和 `#trash` 地址继续兼容。创作空间、素材管理和 Studio 使用相同的 workspace / uploads 云端状态；Studio 删除时保存作品回收状态，恢复时保留原工作区。generationSeen 保存已处理的任务 ID，永久清空后避免生成记录重新导入。跨标签页继续使用现有云端刷新、广播和版本合并。

创作空间与 Studio 共用拖动和双击事件模块。作品可拖到素材管理右侧的回收站图标；素材管理也支持删除按钮和恢复。清空前展示待清理数量并确认；只有云端已标记回收且属于当前用户的文件才允许永久删除。生成音频永久删除时同步清理关联单曲封面、发布记录与占用空间，生成日志保留但解除音频关联；清理失败的项目留在回收站供重试。

Studio 沿用创作空间的 listening-dock 样式、图标、歌词预览和播放时钟，支持双击播放、暂停、进度、音量、前后切换与收藏。播放结束停止，预览和封面更新不重建音频播放器；试听参考音频与结果播放互相暂停。删除当前播放作品后解除其播放器引用。

验证覆盖素材去重、回收与清空后的任务隐藏、账号隔离、关联文件清理、实际浏览器播放、拖放、跨页面恢复、导航保存和移动布局。运行记录与截图保存在被忽略的 output 目录。
